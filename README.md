## How to reproduce

**Google Colab:** open the link above and choose *Runtime → Run all*.
The datasets are downloaded automatically and verified against the MD5 values above.

**Local run:** clone this repository and run the notebook from the repository root;
the files in `data/` are then used directly instead of being downloaded.

The notebook pins scikit-learn 1.8.0 and shap 0.52.0. At the end it compares
35 headline numbers with the reference run; a successful run prints
`SELF-CHECK ... PASS` and `35/35 identical`. The full run takes about 4 minutes on Colab.
